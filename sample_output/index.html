📞 Free Call-Agent Pipeline

Build receptionist / call agents for clients — clinics, real estate, salons, any appointment business — with zero platform fees. One YAML per client, one pipeline for all of them.

LiveKit Agents (Apache-2.0) 100% free demo path No API key needed

▶ A real call — Bright Smile Dental Clinic (demo client)

This transcript was produced by the text simulator in this repo — the same dialogue engine and tools the voice worker uses, driven by typed input instead of speech. Run it yourself: bash scripts/run_simulations.sh

Agent (Maya): Hello, thank you for calling Bright Smile Dental Clinic. This is Maya, how can I help you today?

Caller: Hi, I’d like to book a cleaning appointment

Agent (Maya): Which date works for you? You can say a date like 2027-01-15, or just say tomorrow.

Caller: With Dr. Amina on 2027-01-15 at 10:00

Agent (Maya): Nearly there — could I have your name and phone number to confirm the booking?

Caller: My name is Ayesha Khan, my phone is 07123 456789

Agent (Maya): You’re booked in, Ayesha Khan! Cleaning with Dr. Amina Khan on 2027-01-15 at 10:00–10:45. Your reference code is BRI-000001 — please keep it handy. We’ll see you then!

[tool: book_appointment → ok=True]

Double-booking is impossible: the store enforces it with an overlap check and a partial UNIQUE index on booked rows. Cancelling frees the slot. Full proof in tests/test_store.py.

🏗 How it works

Caller (phone / browser)
        │  WebRTC or SIP
        ▼
LiveKit room ──▶ Agent worker (agent/worker.py)
                    ├─ STT:  faster-whisper (local, free)
                    │         or Deepgram (BYO key)
                    ├─ LLM:  Ollama (local, free)
                    │         or Gemini free tier (BYO key)
                    ├─ TTS:  Piper (local, free)
                    │         or Gemini / Deepgram (BYO key)
                    └─ Tools (agent/tools.py, from client YAML)
                         check_availability · book_appointment
                         cancel / reschedule · hours · services
                         directions · take_message · FAQ
                              │
                              ▼
                    Booking store (SQLite, agent/store.py)
                    double-booking impossible by design

Text simulator (agent/simulate.py) runs the SAME engine
and tools with typed input — no accounts, no keys, no audio.

🚀 Try it — 2 minutes, no account

git clone https://github.com/mrabr381/free-call-agent-pipeline.git
cd free-call-agent-pipeline
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m agent.simulate --config configs/clinic.yaml \
    --script sample_data/call1_book.txt --today 2027-01-10

📞 Go live on voice (LiveKit)

pip install -r requirements-voice.txt
# 1. Create a free LiveKit Cloud project (Build plan: 1,000 agent
#    minutes/month included) and export LIVEKIT_URL, LIVEKIT_API_KEY,
#    LIVEKIT_API_SECRET.
# 2. Download a Piper voice (free, one time):
python -m piper.download_voices en_US-lessac-medium --download-dir voices/
export PIPER_VOICE="$PWD/voices/en_US-lessac-medium.onnx"
# 3. Start Ollama with a local model (or use --llm gemini with a free key):
ollama pull llama3.1
# 4. Check everything resolves, then start the worker:
python -m agent.worker --config configs/clinic.yaml --dry-run
python -m agent.worker --config configs/clinic.yaml
Honest note about phone numbers: the framework, the demo and browser calls are 100% free. A real phone number that customers can dial from their mobiles is not free — the number and per-minute telephony are the client's paid add-on (LiveKit sells US numbers from about $1/month; Twilio/Telnyx are alternatives). The pipeline is built so the number is a configuration detail, not a rebuild.

🆕 Onboard a new client

Copy configs/clinic.yaml, change the business name, persona, hours, services, prices and staff — then run the simulator against it. No code changes. See configs/real-estate.yaml for a second client built exactly this way.
