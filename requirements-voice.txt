# Voice stack — everything the LiveKit worker needs.

# NOTE on faster-whisper + PyAV: faster-whisper 1.2.1 is incompatible with
# the av>=14 that livekit-agents 1.8 requires (it calls av.open with a
# metadata_errors kwarg that av 14 removed). The WhisperSTT adapter works
# around this by decoding audio itself and passing a float32 numpy array to
# faster-whisper, never a file path — so av>=14 stays in place and nothing
# breaks. Do not "fix" this by downgrading av: livekit-agents requires av>=14.
